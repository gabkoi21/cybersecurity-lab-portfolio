# Cybersecurity Lab Portfolio

This repository contains technical documentation from hands-on cybersecurity labs and controlled training environments. Each project focuses on investigation methodology, evidence-based analysis, and clear reporting while excluding sensitive, protected, or fabricated material.

## SOC Investigations

### [Splunk: The Basics](splunk-the-basics/)

**TryHackMe — Splunk: The Basics**

Completed hands-on SIEM training covering Splunk architecture, JSON log ingestion, index creation, field extraction, and VPN log analysis with Search Processing Language (SPL).

**Tool:** Splunk Enterprise

**Status:** Completed

### [Phishing Email Investigation](phishing-email-investigation/)

**TryHackMe SOC Simulator — Introduction to Phishing**

Completed hands-on SOC L1 training covering alert triage, phishing analysis, SIEM investigation, IOC analysis, alert classification, documentation, and escalation workflows.

**Tools:** Splunk · VirusTotal · TryDetectThis

**Status:** Completed

### [Endpoint Detection and Response Investigation](endpoint-detection-response-investigation/)

**TryHackMe — Introduction to EDR**

Completed hands-on endpoint alert triage covering detection review, process-tree analysis, endpoint telemetry, IOC correlation, threat-intelligence context, and response visibility.

**Tool:** Simulated EDR Console

**Status:** Completed

# Investigation Screenshots

This directory is reserved for sanitized screenshots from the simulated EDR investigation. No screenshot image has been added because no approved image was provided.

Useful screenshots may include:

- Detection dashboard overview
- Alert summary and risk assessment
- Process chain for `DESKTOP-HR01`
- Process details showing the Word, CMD, and cURL relationship
- IOC table with non-sensitive lab indicators
- Network activity associated with `WIN-ENG-LAPTOP03`
- Threat-intelligence context for `UpdateAgent.exe`

Before adding an image, confirm that it does not expose TryHackMe flags, credentials, personal information, protected room content, browser-session details, or other material unsuitable for public release. Crop the image to the evidence being discussed and redact unrelated identifiers where appropriate.
